# **App Name**: Sunny's Porfolio

## Core Features:

- Hero Section: Full-screen hero section with split layout, title, subtitle, and subtle animation.
- About Me Section: Displays a profile image, personal bio, education, and tech stack.
- Experience Timeline: Chronological timeline of professional experiences with company name, role, duration, and description.
- Projects Showcase: Interactive project cards with filtering by category (Developer and AI/ML), including project name, image, technologies, description, and a 'Visit' link.
- Certifications Display: Certification cards with name and a 'Verify' link to the certification.
- Contact Form: Contact form that captures the full name, email, and message, then sends an email to sgogoi2004@gmail.com upon submission.
- Sticky Header: Header navigation with smooth scrolling and active section highlighting.

## Style Guidelines:

- Primary color: A saturated cyan (#00FFFF) to reflect glowing and futuristic design.
- Background color: A very dark charcoal (#121212) for the dark theme.
- Accent color: A vivid purple (#D070F0), a color shift analogous to cyan, to be used on highlights.
- Headline font: 'Space Grotesk' sans-serif, for a techy, futuristic feel.
- Body font: 'Inter' sans-serif, for modern and neutral readability.
- Use a set of minimalist icons with a glowing effect on hover for technologies, contact information, and project categories.
- Implement subtle fade-in animations, smooth scrolling transitions, and glowing hover effects on interactive elements.
